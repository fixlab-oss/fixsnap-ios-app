# Project

## App type

Generated iOS SwiftUI application.

## Stack

- SwiftUI
- XcodeGen project generation
- Local state/storage unless the user asks for a backend

## Style

Prefer native Apple-like UI. Avoid web-dashboard-style components unless explicitly requested.

## Important paths

- Project config: `project.yml`
- App source: generated app folder named by the project title
- Generated Xcode project: do not edit `.xcodeproj/project.pbxproj` directly
